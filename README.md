# Hosea Felix Sanjaya

My personal portfolio. Live at **[hoseafelix.dev](https://hoseafelix.dev)**.

## What's on it

- A pick-your-OS screen before you get in. Choose wisely.
- Background built with a WebGL fluid shader that follows your cursor.
- Light and dark themes, switched with a view transition.
- Music player that starts a few seconds after you land ("Misery" by Pupsies), with a pause button in the navbar.
- Projects on 3D tilt cards, plus sections for experience and about.
- A contact form that sends straight to my inbox through Web3Forms.
- The CV is downloadable as a PDF.
- Heavy effects turn off when your system asks for reduced motion.

## Stack

Next.js 16, React 18, TypeScript, Tailwind CSS, Framer Motion. Deployed on Vercel.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3001.
